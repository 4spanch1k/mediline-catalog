# Mediline catalog

Каталог товаров для дома и здоровья на React, TypeScript, Vite и Tailwind CSS. Заказ отправляется как заявка в WhatsApp; сайт не принимает оплату.

## Запуск

```sh
npm install
npm run dev
```

Скопируйте `.env.example` в `.env` и укажите номер WhatsApp. Для локального демо `VITE_SHOW_DEMO_PRODUCTS=true`; перед публикацией каталога с реальными позициями установите `false` и заполните импортированные товары.

Проверки: `npm run lint`, `npm test`, `npx tsc --noEmit`, `npm run build`. Сборка также генерирует `public/sitemap.xml`.

## Товары

Демо-товары описаны в `src/data/products.ts`. Для импорта реальных позиций подготовьте CSV или XLSX по образцу `products.example.csv`, затем сначала проверьте файл:

```sh
npm run products:import -- products.csv --dry-run
npm run products:import -- products.csv
```

Импорт заменяет `src/data/imported-products.json`. Для каждой характеристики используйте три столбца схемы: `spec.<ключ>_ru`, `spec.<ключ>_kz`, `spec.<ключ>_en`. Ключи и порядок задаются в `src/data/specSchema.ts`; пример есть в `products.example.csv`. Заполняйте все три языка или оставляйте их пустыми. Фотографии не загружаются по внешним ссылкам: положите их в `public/assets/products/<slug>/` и укажите локальный путь, например `/assets/products/philips-led-classic/1.webp`. Импортёр проверит существование файла. `ProductImage` использует фото товара или отдельный SVG-плейсхолдер.

У 60 демо-позиций есть по два локальных сгенерированных изображения на светлом фоне. Они иллюстрируют тип товара, но не подтверждают точный внешний вид или комплектацию указанной модели; перед публикацией замените их официальными фотографиями.

Иллюстрации категорий находятся в `public/assets/categories/`. Чтобы заменить иллюстрацию фотографией, положите оптимизированный WebP-файл в эту папку и обновите путь изображения в `src/components/MobileCategoryTiles.tsx`. Для квадратной плитки лучше подходит изображение с предметом по центру на светлом фоне.

Чтобы оставить только реальные импортированные позиции, задайте `VITE_SHOW_DEMO_PRODUCTS=false`. Перед этим убедитесь, что импорт не пуст.

## Настройки и бренд

- `VITE_WHATSAPP_NUMBER`: номер только цифрами, без `+`; `wa.me` и `tel:` строятся из него.
- `VITE_CONTACT_ADDRESS`, `VITE_CONTACT_EMAIL`: контакты. Если пусто, интерфейс показывает, что данные уточняются.
- `VITE_GA4_ID`, `VITE_META_PIXEL_ID`: необязательные ID аналитики; пустые значения отключают загрузку аналитических скриптов.
- `VITE_SHOW_DEMO_PRODUCTS`: переключает набор демо-позиций.
- Логотип меняется в `src/assets/logo.svg`; favicon — в `public/favicon.svg`.

## Структура и публикация

- `src/data/` — каталог и импортированные данные;
- `src/types/` — модели;
- `src/pages/`, `src/components/` — страницы и интерфейс;
- `src/hooks/`, `src/lib/` — состояние и логика;
- `src/i18n/` — тексты ru/kz/en;
- `src/config/site.ts` — настройки, читаемые из `.env`.

Vercel использует `vercel.json` для SPA-маршрутов. Подключите репозиторий в Vercel, добавьте переменные окружения, укажите домен `mediline.asia` в настройках проекта и подтвердите DNS у регистратора. Приложение — client-rendered SPA: метаданные обновляются после загрузки JavaScript, поэтому предпросмотр ссылок и часть поисковых роботов могут видеть общий HTML; при необходимости добавьте prerender перед запуском SEO-кампании.

## Иконки и источники

Интерфейс использует локальные PNG-иконки из Flaticon (`public/assets/icons/`). В подвале добавлена ссылка на источник. Перед коммерческой публикацией сопоставьте каждый PNG с его автором и добавьте видимую атрибуцию автора согласно выбранной лицензии Flaticon.
